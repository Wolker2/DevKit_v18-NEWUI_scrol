DevKit V18 TEST — выбор планеты или космоса после системы

Порядок выбора:
1. DevKit → «Телепортация в другую систему» → выбрать систему.
2. Откроется стандартный список: «Космос» и названия доступных заселённых
   планет именно этой системы.
3. «Космос» — закрытие прежних окон и перенос в космос выбранной системы.
4. Название планеты — закрытие прежних окон, перенос и открытие экрана
   выбранной планеты. Штатные события прибытия/правительства сохраняются.
5. Отмена второго списка оставляет DevKit открытым и отменяет временный
   приказ телепортации; переноса не будет.

В список входят планеты с населением больше нуля и владельцем одной из
обычных рас либо пиратов. Необитаемые/доминаторские планеты не выводятся.
В доминаторских системах доступен «Космос»: штатный экран Planet в таких
системах запускает завершение партии (проверено по исходникам движка).
Если планет для посадки нет, в списке остаётся «Космос».

Перенос выполняется только после закрытия старых окон, как в V17.
Колёсико, кнопки навигации, координаты и восстановление кнопки сохранены.
DLL прокрутки из V17 не изменена, новых зависимостей не добавлено.

Установка: полностью заменить Mods\Tweaks\DevKit и перезапустить игру.
Новая игра не нужна. В корневую папку игры ничего копировать не требуется.

Проверка: система с несколькими планетами → выбрать планету; повторить
для «Космос»; проверить отмену, систему без обитаемых планет и повторный
вызов DevKit после прибытия. В лог пишутся только выбор и тип прибытия.

Проверено статически: ZIP, DAT roundtrip, точная область изменений,
сохранение прокрутки/кнопок/отмены и исходные значения владельцев.
Реальный игровой запуск V18 здесь недоступен; статус TEST.
