# DevKit v18 — восстановленные исходники для GitHub

**Проверено 28 октября 2026 года: все 22 файла мода пересобраны из редактируемых исходников и побайтово совпали с оригиналом.** Получение `.rson` на компьютере пользователя не требуется: он уже включён в проект, а сборка полностью выполняется без Windows и RScript.

В проект включены:

- `source/script/Mod_DevKit.rson` — восстановленные переменные, объекты и весь код SCR;
- `source/script/Mod_DevKit.layout.json` — открытая схема записи полей в формат SCR8;
- `source/config/*.json` — исходники трёх DAT;
- `source/native/wheel/` — исходник DLL на C, тесты и сборщик;
- `source/graphics/layers/*.json` — точные исходные слои всех 16 GI;
- `source/graphics/*.png` — изображения для просмотра;
- `source/module/ModuleInfo.txt` — редактируемое описание мода;
- `docs/` — инструкции сборки, результаты проверки и пояснение для модераторов Nexus;
- `.github/workflows/build.yml` — автоматическая сборка и проверки GitHub Actions.

Оригинальные 22 файла отдельно сохранены в `original/DevKit/`. Сборщик не использует их как входные данные: это проверено отдельной сборкой в каталоге, содержащем только исходники, инструменты сборки и список эталонных SHA-256.

## Сборка для проверяющих

Linux, Python 3.10+, GCC и GNU binutils:

```sh
python3 scripts/build.py --strict-original
python3 -m unittest discover -s tests -v
```

Результат: `dist/DevKit_v18_FROM_SOURCE.zip` и `dist/build-report.json`. Полная инструкция: [docs/BUILD.md](docs/BUILD.md). Эти команды уже выполнены при подготовке проекта.

## Что именно восстановлено в RSON

Полностью разобран оригинальный SCR размером 253 142 байта: 1 глобальная и 34 локальные записи переменных, объекты мира, состояние, 4 диалога, 14 сообщений и 78 ответов. Восстановлен весь хранящийся в SCR код, включая комментарии. Обратная сборка через включённый Python-кодек дала оригинальный SCR без изменения единого байта.

Координаты узлов редактора созданы заново. Схема `layout.json` задаёт порядок сериализации полей из RSON; она не содержит скрытых бинарных блоков кода. При добавлении или удалении узлов нужно также менять эту схему. Сборщик предназначен для восстановленной модели DevKit, а не для произвольных проектов RScript.

Структурная проверка RSON через SRHD-XenoModKit 0.10.4 прошла без замечаний. Открытие и компиляция в самом RScript 4.15f не выполнялись; для поставляемой автономной сборки он не нужен.

## Проверки и статус

Пять автоматических проверок прошли: полный SCR, изменение кода с пересчётом смещения, изменение начального значения переменной, точная пересборка графики и сборка без готовых бинарных файлов. Дополнительно прошли C-тесты DLL и проверка всех 22 SHA-256. Подробности: [docs/VERIFICATION.md](docs/VERIFICATION.md).

Исходный мод имеет статус TEST. Побайтовое совпадение подтверждает сохранение его содержимого; запуск игры и решение администрации Nexus не проверялись.

Авторские указания `noname, Prolog_D` и зависимость `UtilityFunctionsPack` сохранены.
